# GoldBot — сигналы и торговля XAUUSD M5

Бот находит сетапы на M5, присылает сигналы в Telegram и по ним же открывает
сделки в MetaTrader 5. Работает двумя окнами: анализатор и исполнитель.

## Что нужно

- Windows, Python 3.10+ (обязательно 64-битный)
- MetaTrader 5 с символом **XAUUSD**, включённый алготрейдинг
- (по желанию) Telegram-бот для сигналов

Терминал должен быть установлен и запущен. Если он стоит в нестандартной папке,
путь указывается один раз в `.env`:

```
TERMINAL_PATH=D:\MetaTrader 5\terminal64.exe
```

После этого `start_bot.bat` и `start_executor.bat` запускаются двойным кликом.
Флаг `--terminal "путь\terminal64.exe"` тоже работает, если удобнее разово.

## Установка

```bat
git clone https://github.com/cirkulik/TraderBot.git
cd TraderBot
pip install -r requirements.txt
copy config.example.json config.json
copy .env.example .env
```

## Что вписать от себя

| данные | где взять | куда вписать |
|---|---|---|
| **Токен бота** | [@BotFather](https://t.me/BotFather) → `/newbot` → токен вида `123456:AA...` | `.env` → `TELEGRAM_TOKEN=` |
| **ID чата** | запустить `python telegram_setup.py --wait 120` и написать боту — скрипт сам найдёт и сохранит | `.env` → `TELEGRAM_CHAT_ID=` |
| **Счёт MT5** | логин, пароль, сервер (например `MetaQuotes-Demo`) | спросит исполнитель при запуске |
| **Лот** | размер позиции, например `0.01` | спросит исполнитель при запуске |

`.env` и `config.json` в репозиторий не попадают — там ваши личные данные.

## Запуск

Две консоли:

```bat
:: окно 1 — сигналы
python run_live.py

:: окно 2 — сделки
python run_executor.py
```

Или двойными кликами: `start_bot.bat` и `start_executor.bat`.

Исполнитель спросит:

```
Вход в торговый счёт MT5
  Enter без логина — использовать счёт, открытый в терминале.
Логин MT5: 12345678
Пароль MT5: ********
Сервер [MetaQuotes-Demo]:
Запомнить в data/account.json? (y/n):

Настройки исполнения
  Лот (Enter — оставить 0.01):
```

Пароль виден при вводе. Для реального счёта учитывайте, что он останется
в истории консоли.

Ответить `y` — и в следующий раз вход будет автоматическим. Enter без логина —
работать со счётом, который уже открыт в терминале.

Лот можно менять на ходу: поправьте `execution.lot` в `config.json` —
исполнитель подхватит за пару секунд, перезапуск не нужен.

## Что происходит дальше

1. На закрытии бара M5 анализатор находит сетап и отправляет сигнал в Telegram:
   направление, вход, SL, TP, причина.
2. Исполнитель видит новый сигнал и открывает ордер с этим SL и TP.
3. Дальше сделку ведёт брокер. Итог пишется в `data/executor.csv`.

## Команды в Telegram

| команда | что делает |
|---|---|
| `/allow 123456789` или `/allow @nick` | выдать доступ |
| `/deny <id\|@nick>` | приостановить доступ |
| `/remove <id\|@nick>` | удалить |
| `/users` | список пользователей |
| `/lang` | язык (ru / az) |

Доступ только по белому списку: посторонним бот не отвечает и сигналы не шлёт.

## Важно

Сначала демо-счёт. Лот 0.01 при SL 6 $ — это 6 $ риска на сделку: на счёте
100 $ это 6 %, на 1000 $ — 0.6 %. Торговля с плечом может привести к потере
средств; ответственность за решения лежит на вас.
