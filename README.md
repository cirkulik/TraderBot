# GoldBot — сигналы и автоторговля XAUUSD M5

Два независимых процесса для MetaTrader 5:

1. **Анализатор** (`run_live.py`) — ищет сетапы на закрытии каждого бара M5,
   пишет сигналы (направление, вход, SL, TP, причина) в журнал
   `data/signals.csv` и рассылает их в Telegram по белому списку.
2. **Исполнитель** (`run_executor.py`) — отдельное окно. Читает журнал и
   открывает рыночные ордера с фиксированным лотом, SL и TP из сигнала.
   Дальше позицию ведёт брокер.

Анализатор ничего не знает про сделки, исполнитель ничего не знает про
стратегию. Можно запускать только анализатор — тогда бот просто сигналит.

> **Важно:** стратегия торгует внутридневно на M5. Перед реальными деньгами
> прогоните бэктест и неделю поторгуйте на демо-счёте.

---

## Что нужно

- Windows (библиотека `MetaTrader5` работает только под Windows).
- Python 3.10+.
- Установленный терминал MetaTrader 5 с доступом к символу **XAUUSD**.
- (Необязательно) Telegram-бот для рассылки сигналов.

## Установка

```bat
git clone https://github.com/cirkulik/TraderBot.git
cd TraderBot
pip install -r requirements.txt
```

Запустите терминал MetaTrader 5, войдите в свой счёт и добавьте XAUUSD в
«Обзор рынка». В настройках терминала включите **Алготрейдинг**
(Сервис → Настройки → Советники → «Разрешить алгоритмическую торговлю»).

## Настройка

```bat
copy config.example.json config.json
```

`config.json` в репозиторий не попадает — в нём ваши личные данные.

### Telegram (необязательно)

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Впишите токен в `config.json`:

```json
"telegram": {
  "enabled": true,
  "token": "123456:AA...",
  "chat_id": "",
  ...
}
```

3. Запустите привязку администратора — скрипт сам поймёт, кто написал боту,
   и запишет `chat_id`:

```bat
python telegram_setup.py --wait 120
```

Напишите своему боту любое сообщение в течение двух минут. После этого
администратор получает сигналы и управляет доступом:

| команда | что делает |
|---|---|
| `/allow 123456789` или `/allow @nick` | выдать доступ |
| `/deny <id\|@nick>` | приостановить доступ |
| `/remove <id\|@nick>` | удалить пользователя |
| `/users` | список пользователей |
| `/lang` | сменить язык (ru / az) |

Посторонние люди боту писать могут, но он их полностью игнорирует: доступа
нет, ответа нет, заявок на «разрешить» нет.

### Символ и стратегия

Основные настройки — в `config.json`:

| ключ | смысл |
|---|---|
| `symbol`, `timeframe` | инструмент и таймфрейм (по умолчанию XAUUSD M5) |
| `max_spread_points` | не выдавать сигнал при спреде больше N пунктов |
| `max_risk_price` | не выдавать сигнал, если SL дальше N $ по цене |
| `strategy.setups.*` | сетапы: направление, сессия, триггер, SL/TP, время выхода |
| `strategy.cooldown_bars` | пауза после сделки в барах |
| `strategy.max_signals_per_day` | лимит сигналов в день |
| `backtest.spread_points` | спред для бэктеста |

Включённые сетапы: `dip_london`, `dip_late`, `sell_noon`, `rsi_ny`,
`stretch_ny`, `sell_break`. Каждый можно выключить через `"enabled": false`.

## Запуск

Две консоли:

```bat
:: окно 1 — анализатор и сигналы в Telegram
python run_live.py

:: окно 2 — исполнение сигналов на счёте MT5
python run_executor.py
```

Или двойными кликами: `start_bot.bat` и `start_executor.bat`.

Анализатор пишет:

```
[16.11 12:00 сервер / 10:00 UTC] цена 4012.34/4012.55  спред 21
[сигнал] SELL sell_noon 4012.34 SL 4018.10 TP 4005.44 (1.20R)
```

## Исполнитель: счёт и лот

При запуске исполнитель спрашивает счёт:

```
Вход в торговый счёт MT5
  Enter без логина — использовать счёт, открытый в терминале.
Логин MT5: 12345678
Пароль MT5 (ввод не отображается):
Сервер [MetaQuotes-Demo]:
Запомнить в data/account.json? (y/n):
```

- **Enter без логина** — работать со счётом, в который залогинен терминал.
- `y` сохраняет логин/пароль/сервер в `data/account.json` (файл в `.gitignore`,
  пароль хранится в открытом виде — не публикуйте его).
- `python run_executor.py --forget` — забыть сохранённый счёт.
- `python run_executor.py --login 12345678 --server MetaQuotes-Demo` — без
  вопросов о счёте.

Дальше спрашивается лот:

```
Настройки исполнения
  Лот (Enter — оставить 0.01):
```

- Ввели `0.05` — сделки пойдут с 0.05, значение сохранится в `config.json`.
- Enter — оставить текущее.
- Поменять на ходу: исправьте `execution.lot` в `config.json`, исполнитель
  подхватит за пару секунд (`лот изменён: 0.01 -> 0.05`). Перезапуск не нужен.
- Разово: `python run_executor.py --lot 0.05`.

Риск в деньгах = `risk_price × 100 × lot`. Пример: SL 6 $ по цене и лот 0.01
дают 6 $ риска на сделку. Считайте от баланса: на 1000 $ это 0.6 %, на 100 $ —
6 %.

Остальные настройки исполнения:

| ключ | смысл |
|---|---|
| `execution.enabled` | включён ли исполнитель |
| `execution.lot` | лот по умолчанию |
| `execution.max_positions` | сколько позиций держать одновременно (1 — как в бэктесте) |
| `execution.max_signal_age_minutes` | сигналы старше N минут не исполняются |
| `execution.max_entry_slip_points` | пропускать, если цена ушла от сигнальной дальше N пунктов |
| `execution.magic` | метка позиций бота; по ней они находятся после перезапуска |

Что делает исполнитель: ставит SL и TP сразу в заявке, не больше
`max_positions` позиций, пишет всё в `data/executor.csv` и `data/executor.log`.
Чего не делает: не двигает стоп, не закрывает вручную, не считает лот от риска.

Проверка без отправки ордеров:

```bat
python run_executor.py --dry-run --once
```

## Бэктест

```bat
python run_backtest.py                     :: обычный прогон
python run_backtest.py --refresh           :: заново скачать историю
python run_backtest.py --realistic         :: жёсткие условия исполнения
python run_backtest.py --start 2026-01-01 --end 2026-11-01
python run_backtest.py --tune              :: устойчивость параметров
```

`--realistic` — стресс-проверка: вход по открытию следующего бара,
проскальзывание 5 пунктов, спред 21 пункт. Результаты пишутся в `reports/`
(папка в `.gitignore`).

История скачивается из терминала и кешируется в `data/XAUUSD_M5.csv`, поэтому
первый прогон медленнее, а повторные — быстрые.

## Структура проекта

```
config.example.json    шаблон настроек
run_live.py            анализатор: сигналы и Telegram
run_executor.py        исполнитель: сделки на счёте MT5
run_backtest.py        бэктест и проверка параметров
journal_stats.py       статистика по журналу сигналов
telegram_setup.py      привязка администратора Telegram
goldbot/
  config.py            загрузка/слияние настроек
  data.py              подключение к MT5, котировки, кеш, вход в счёт
  indicators.py        EMA, RSI, ATR, ADX
  strategy.py          сетапы и расчёт SL/TP
  backtest.py          симуляция сделок и метрики
  live.py              live-цикл, журнал сигналов
  executor.py          ордера по сигналам, лот, сверка позиций
  telegram.py          рассылка, команды, выбор языка
  i18n.py              тексты на русском и азербайджанском
  subscribers.py       пользователи и доступ (SQLite)
data/                  создаётся автоматически: журнал, база, кеш
```

## Как это работает

- Сигнал считается на **закрытии** бара M5 — внутри бара ничего не
  подглядывается.
- Одна позиция за раз, пауза после сделки (`cooldown_bars`) — как в бэктесте.
- SL/TP фиксированные, выход по времени (`time_exit_bars`), если ни то ни
  другое не сработало.
- Telegram-доступ только по белому списку, база — SQLite (`data/goldbot.db`).

## Если что-то не работает

| симптом | что проверить |
|---|---|
| `Не удалось подключиться к MetaTrader 5` | терминал запущен, алготрейдинг включён |
| `Символ XAUUSD не найден` | добавьте XAUUSD в «Обзор рынка» |
| мало истории / пустой бэктест | откройте график XAUUSD M5 в терминале и прокрутите назад |
| сигналы не приходят в Telegram | токен и `chat_id` в `config.json`, доступ выдан через `/allow` |
| исполнитель пишет `не хватает маржи` | уменьшите лот или пополните счёт |
| исполнитель пишет `рынок закрыт` | вне торговой сессии ордера не отправляются |
